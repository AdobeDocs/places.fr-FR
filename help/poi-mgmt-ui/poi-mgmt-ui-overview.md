# Présentation de l’interface utilisateur du service Places {#management-ui-overview}

Les POI et les bibliothèques sont créés et gérés dans la base de données Places Service à l&#39;aide de l&#39;interface utilisateur Places Service.

* Pour créer une bibliothèque ou gérer plusieurs bibliothèques, consultez [Gestion des bibliothèques](/help/poi-mgmt-ui/manage-libraries-in-the-places-ui.md).
* Pour créer un point d’intérêt, voir [Créer un point d’intérêt](/help/poi-mgmt-ui/create-a-poi-ui.md).
* Pour gérer plusieurs points d’intérêt, voir [Gérer les points d’intérêt créés précédemment](/help/poi-mgmt-ui/managing-pois-in-the-places-ui.md).
* Pour effectuer une importation en bloc des points d’intérêt, voir [Importation en bloc des points d’intérêt](/help/poi-mgmt-ui/bulk-upload-pois.md).
